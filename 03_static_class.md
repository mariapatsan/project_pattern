# Статический класс

## Описание

В Python нет отдельного ключевого слова или специальной конструкции `static class`, как, например, в некоторых других языках программирования. Однако в учебных задачах под статическим классом обычно понимают класс, который используется без создания его экземпляров.

Такой класс объединяет общие данные и функции, которые логически связаны между собой. Для обращения к ним достаточно указать имя класса, создавать объекты не требуется.

Например, можно создать класс `Library`, который хранит общую информацию о библиотеке и предоставляет методы для работы с ней.

## Ключевые особенности

- Отсутствие экземпляров. Для использования такого класса не требуется создавать объекты с помощью вызова `Library()`.
- Обращение через имя класса. Атрибуты и методы вызываются напрямую: `Library.attribute` или `Library.method()`.
- Общие данные. Атрибуты класса доступны через само имя класса и могут использоваться всеми частями программы.
- Статические методы. Для функций, которым не нужны данные конкретного объекта, применяется декоратор `@staticmethod`.
- Организация кода. Такой подход позволяет объединить связанные функции и константы в одном месте.

**Важно:** обычный класс Python не становится технически «статическим» только потому, что мы не создаём его экземпляры. Это скорее способ организации программы.

## Пример

``` python
class Library:    
    """Класс для хранения общей информации о библиотеке"""    
    # Атрибуты класса    
    name = "Центральная библиотека"   
    books_count = 1500    
    
    @staticmethod    
    def get_info():        
        """Возвращает информацию о библиотеке"""        
        return f"Библиотека: {Library.name}, количество книг: {Library.books_count}"    
        
    @staticmethod    
    def is_open(hour: int) -> bool:        
        """Проверяет, открыта ли библиотека в указанное время"""        
        return 9 <= hour < 18

# Обращение к атрибутам и методам через имя класса
print(Library.name)
print(Library.books_count)
print(Library.get_info())
print(Library.is_open(12))
print(Library.is_open(20))
```

Шаги в программе:

1. Объявление класса. С помощью `class Library` создаётся класс, объединяющий информацию и функции, связанные с библиотекой.
2. Создание атрибутов класса. `name` и `books_count` хранят общую информацию. Они принадлежат классу и доступны через его имя.
3. Объявление статических методов. Декоратор `@staticmethod` указывает, что метод не получает автоматически ни `self`, ни `cls`. Поэтому ему не нужны данные конкретного экземпляра.
4. Метод `get_info()`. Возвращает строку с информацией о библиотеке. Для доступа к атрибутам используется имя класса `Library`.
5. Метод `is_open()`. Принимает час в качестве аргумента и возвращает `True`, если библиотека открыта, или `False`, если закрыта.
6. Вызов методов. Атрибуты и методы вызываются непосредственно через `Library`. Создавать объект класса для этого не требуется.

## Учебное задание

Создайте класс `University`, который будет использоваться без создания экземпляров.

1. Добавьте атрибуты класса:

`name` — название университета;

`students_count` — количество студентов;

`city` — город, в котором находится университет.

2. Создайте статический метод `get_info()`, который возвращает общую информацию об университете.
3. Создайте статический метод `is_student_count_valid(count)`, который проверяет, что переданное количество студентов больше нуля. Метод должен возвращать `True` или `False`.
4. Обратитесь к атрибутам и методам через имя класса `University`, не создавая его экземпляров.
5. Выведите результаты работы методов на экран.
