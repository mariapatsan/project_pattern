# Создание объектов

## Описание

Объект (экземпляр) — это конкретная сущность, созданная по шаблону класса. Если класс — это чертёж, то объект — это дом, построенный по этому чертежу. У каждого объекта свои значения атрибутов экземпляра, но структура и поведение (методы) общие, потому что они заданы классом.

## Ключевые особенности

- Объект создаётся вызовом класса: `obj = MyClass(...)`. Скобки обязательны — без них вы получите ссылку на сам класс, а не на объект.
- При создании Python сам вызывает `__init__` — вручную его вызывать не нужно.
- Каждый вызов класса создаёт новый независимый объект: изменения одного не влияют на другой.
- Присваивание `a = b` не копирует объект, а копирует ссылку на него. После `a = b` обе переменные указывают на один и тот же объект.
- Проверить тип объекта можно через `isinstance(obj, Cls)` или `type(obj)`.
- Сравнение `obj1 is obj2` проверяет, один ли это объект (адрес в памяти), а `obj1 == obj2` — равенство по значению (если определено `__eq__`).

## Пример

```python
class Book:
    """Класс, описывающий книгу"""

    material = "paper"

    def __init__(self, title: str, author: str, pages: int):
        self.title = title
        self.author = author
        self.pages = pages

    def __str__(self) -> str:
        return f"«{self.title}» — {self.author}, {self.pages} стр."


# Создание объектов класса Book
book1 = Book("Война и мир", "Лев Толстой", 1052)
book2 = Book("Преступление и наказание", "Фёдор Достоевский", 672)

# Вывод объектов
print(book1)
print(book2)

# Обращение к атрибутам объектов
print(book1.title)
print(book2.author)

# Проверка независимости объектов
book1.pages = 500

print(book1.pages)
print(book2.pages)

# Проверка идентичности объектов
book3 = book1

print(book1 is book2)  # False
print(book1 is book3)  # True
```

Шаги в программе:

1. book1 = Book(...) — создаём первый объект класса Book, передавая ему название книги, автора и количество страниц.

2. book2 = Book(...) — создаём второй независимый объект того же класса с другими характеристиками.

3. При создании каждого объекта автоматически вызывается метод __init__(), который сохраняет переданные значения в атрибутах экземпляра.

4. print(book1) и print(book2) — выводим объекты. Python автоматически вызывает метод __str__(), чтобы получить их текстовое представление.

5. book1.title и book2.author — обращаемся к атрибутам объектов через точку.

6. book1.pages = 500 — изменяем количество страниц первой книги. Значение второго объекта при этом не меняется, поскольку у каждого объекта собственные атрибуты экземпляра.

## Учебное задание

Создайте класс Student, описывающий студента, и продемонстрируйте создание и использование его объектов.

Требования:

1. Класс должен содержать атрибуты экземпляра:

name (строка) — имя студента;

group (строка) — номер группы;

grades (список целых чисел) — оценки студента.

2. В методе __init__() реализуйте инициализацию указанных атрибутов.

3. Создайте метод __str__(), который возвращает строку с именем студента и номером его группы.

4. Создайте три объекта класса Student с разными данными.

5. Выведите информацию о каждом объекте с помощью print().

6. Измените оценку одного студента и продемонстрируйте, что данные остальных объектов не изменились.
