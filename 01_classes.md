# Создание классов

## Описание

Класс — это своеобразный шаблон, по которому создаются объекты. Он описывает, какими характеристиками (атрибутами) и действиями (методами) будут обладать объекты определённого типа.

## Ключевые особенности

- Для объявления класса используется ключевое слово class.
- Названия классов принято писать в стиле PascalCase — каждое слово начинается с - заглавной буквы.
- Атрибуты описывают характеристики объектов.
- Методы — это функции, определённые внутри класса.
- Метод __init__() автоматически вызывается при создании объекта и используется для его первоначальной настройки.
- Параметр self обозначает конкретный экземпляр класса, с которым работает метод.

## Пример

``` python
class Book:
    """Класс, описывающий книгу"""

    # Атрибут класса одинаковый для всех
    material = "paper"

    def __init__(self, title: str, author: str, pages: int):
        # Атрибуты экземпляра у каждого экземпляра свои
        self.title = title
        self.author = author
        self.pages = pages

    def __str__(self) -> str:
        return f"«{self.title}» — {self.author}, {self.pages} стр."
```

Шаги в программе:

1. class Book: - объявили класс.
2. material = "paper" - атрибут класса, общий для всех книг.
3. def __init__(self, title, author, pages): - конструктор; self - ссылка на создаваемый объект.
4. self.title = title и т.д. - сохраняем переданные значения в атрибуты экземпляра.
5. def __str__(self): - определяет, что вернёт print(b) и str(b).
6. b = Book(...) - Python создаёт объект и автоматически вызывает __init__.

## Учебное задание

Создайте класс Student, описывающий студента, со следующими требованиями:

1. Атрибут класса university = "Herzen" — общий для всех студентов.

2. Атрибуты экземпляра, задаваемые в __init__:

name (строка) — имя студента;

group (строка) — номер группы;

grades (список целых чисел) — оценки студента.

3. Метод average(self) — возвращает средний балл студента. Если список оценок пуст, вернуть 0.0.

4. Магический метод __str__ — возвращает строку вида:
Студент Иван (группа P3210), средний балл: 4.5.

5. В блоке проверки (под классом) создайте двух студентов с разными данными, выведите каждого через print(), а также выведите Student.university и s1.university, чтобы убедиться, что атрибут класса доступен и через класс, и через экземпляр.
